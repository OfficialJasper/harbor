These commands control Harbor's automated security modules — the core of what the bot does. Each module operates independently, so you can enable only the protections relevant to your server. Use the commands in each section to turn a module on or off, adjust its detection thresholds, set the automated response action, and check its current state — all without leaving Discord.

---

<Accordion title="Anti-Raid Commands">

The anti-raid module monitors join rates and triggers a lockdown when the threshold is exceeded.

**`/harbor anti-raid enable`**
Enable the anti-raid module.
```
/harbor anti-raid enable
```

**`/harbor anti-raid disable`**
Disable the anti-raid module.
```
/harbor anti-raid disable
```

**`/harbor anti-raid threshold`**
Set the number of joins within a rolling time window that triggers raid detection.
```
/harbor anti-raid threshold:[N] window:[S]
```

| Parameter | Description |
|---|---|
| `threshold` | Number of joins required to trigger the module (e.g. `10`). |
| `window` | Rolling time window in seconds (e.g. `30`). |

**`/harbor anti-raid action`**
Set the automated action taken against accounts caught in a raid.
```
/harbor anti-raid action:[kick|ban|mute]
```

| Value | Behavior |
|---|---|
| `kick` | Remove joining accounts during lockdown. |
| `ban` | Permanently ban joining accounts during lockdown. |
| `mute` | Mute joining accounts and hold for review. |

**`/harbor anti-raid unlock`**
Manually end an active lockdown before the cooldown expires.
```
/harbor anti-raid unlock
```

**`/harbor anti-raid status`**
Display the current anti-raid configuration and lockdown state.
```
/harbor anti-raid status
```

</Accordion>

<Accordion title="Anti-Nuke Commands">

The anti-nuke module detects destructive bulk actions by server members or compromised admin accounts, such as mass channel deletions, mass role deletions, or mass bans.

**`/harbor anti-nuke enable`**
Enable the anti-nuke module.
```
/harbor anti-nuke enable
```

**`/harbor anti-nuke disable`**
Disable the anti-nuke module.
```
/harbor anti-nuke disable
```

**`/harbor anti-nuke threshold`**
Set the number of destructive actions within a short window that triggers the module.
```
/harbor anti-nuke threshold channel:[N] role:[N] ban:[N]
```

| Parameter | Description |
|---|---|
| `channel` | Number of channel deletions/creations before triggering (e.g. `5`). |
| `role` | Number of role deletions/modifications before triggering (e.g. `5`). |
| `ban` | Number of bans issued before triggering (e.g. `5`). |

**`/harbor anti-nuke action`**
Set what Harbor does to an account detected performing a nuke attempt.
```
/harbor anti-nuke action:[strip-perms|ban]
```

| Value | Behavior |
|---|---|
| `strip-perms` | Immediately remove all permissions from the offending account. |
| `ban` | Permanently ban the offending account. |

**`/harbor anti-nuke status`**
Display the current anti-nuke configuration.
```
/harbor anti-nuke status
```

</Accordion>

<Accordion title="Anti-Spam Commands">

The anti-spam module monitors message frequency, mention counts, and emoji usage, acting automatically when members exceed configured limits.

**`/harbor anti-spam enable`**
Enable the anti-spam module.
```
/harbor anti-spam enable
```

**`/harbor anti-spam disable`**
Disable the anti-spam module.
```
/harbor anti-spam disable
```

**`/harbor anti-spam max-messages`**
Set the maximum number of messages a user can send within a rolling window.
```
/harbor anti-spam max-messages:[N] window:[S]
```

| Parameter | Description |
|---|---|
| `max-messages` | Message limit (e.g. `8`). |
| `window` | Rolling window in seconds (e.g. `5`). |

**`/harbor anti-spam max-mentions`**
Set the maximum number of user mentions allowed in a single message.
```
/harbor anti-spam max-mentions:[N]
```

**`/harbor anti-spam max-emojis`**
Set the maximum number of emojis allowed in a single message.
```
/harbor anti-spam max-emojis:[N]
```

**`/harbor anti-spam action`**
Set the automated action taken when the spam threshold is exceeded.
```
/harbor anti-spam action:[delete|warn|mute|kick]
```

| Value | Behavior |
|---|---|
| `delete` | Delete the offending message(s) only. |
| `warn` | Delete and issue a formal warning. |
| `mute` | Delete and mute the member. |
| `kick` | Delete and kick the member. |

**`/harbor anti-spam exempt`**
Exempt a specific channel from all spam checks. Useful for bot command channels or media channels.
```
/harbor anti-spam exempt channel:#channel
```

**`/harbor anti-spam status`**
Display the current anti-spam configuration.
```
/harbor anti-spam status
```

</Accordion>

**`/harbor anti-bot disable`**

</Accordion>

<Accordion title="Verification Commands">

The verification module requires new members to complete a verification step before gaining access to the server, reducing bot joins and raid accounts.

**`/harbor verify enable`**
Enable the verification module.
```
/harbor verify enable
```

**`/harbor verify disable`**
Disable the verification module.
```
/harbor verify disable
```

**`/harbor verify mode`**
Set the type of verification challenge presented to new members.
```
/harbor verify mode:[reaction|button|captcha]
```

| Value | Description |
|---|---|
| `reaction` | Member reacts to a message to verify. |
| `button` | Member clicks a button component to verify. |
| `captcha` | Member completes a text-based captcha challenge. |

**`/harbor verify channel`**
Set the channel where the verification prompt is posted.
```
/harbor verify channel:#channel
```

**`/harbor verify role`**
Set the role assigned to members after they successfully verify.
```
/harbor verify role:@Role
```

**`/harbor verify unverified-role`**
Set a role applied to members who have not yet verified, restricting their access until they do.
```
/harbor verify unverified-role:@Role
```

**`/harbor verify timeout`**
Set how long a new member has to complete verification before being kicked.
```
/harbor verify timeout:[MINUTES]
```

**`/harbor verify status`**
Display the current verification configuration.
```
/harbor verify status
```

</Accordion>

<Accordion title="Threat Detection Commands">

The threat detection module analyzes member behavior and account signals to assign threat scores. Flagged accounts can be reviewed before automated action is taken.

**`/harbor threat-detection enable`**
Enable the threat detection module.
```
/harbor threat-detection enable
```

**`/harbor threat-detection disable`**
Disable the threat detection module.
```
/harbor threat-detection disable
```

**`/harbor threat-detection action-threshold`**
Set the threat score at which Harbor automatically acts on a flagged account.
```
/harbor threat-detection action-threshold:[SCORE]
```

| Parameter | Description |
|---|---|
| `action-threshold` | Numeric score (e.g. `75`) above which automated action triggers. |

**`/harbor flags list`**
View all currently flagged members and their threat scores.
```
/harbor flags list
```

**`/harbor flags review`**
Review the detailed threat breakdown for a specific user.
```
/harbor flags review user:@User
```

**`/harbor flags clear`**
Clear the threat flag from a user, removing them from the flagged list.
```
/harbor flags clear user:@User
```

</Accordion>

<Accordion title="Whitelist Commands">

The whitelist exempts specific users, roles, or bots from all Harbor System automated checks. Use this for trusted bots, staff accounts, and administrative roles.

**`/harbor whitelist add user`**
Add a specific user to the whitelist.
```
/harbor whitelist add user:@User
```

**`/harbor whitelist add role`**
Add an entire role to the whitelist. All members holding the role are exempt.
```
/harbor whitelist add role:@Role
```

**`/harbor whitelist add bot`**
Add a bot by its application ID to the whitelist, exempting it from anti-bot checks.
```
/harbor whitelist add bot:[BOT_ID]
```

**`/harbor whitelist remove user`**
Remove a user from the whitelist.
```
/harbor whitelist remove user:@User
```

**`/harbor whitelist list`**
View all currently whitelisted users, roles, and bots.
```
/harbor whitelist list
```

</Accordion>
