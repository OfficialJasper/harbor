These commands manage Harbor System's global server settings — the foundation everything else builds on. They are distinct from the individual security module settings (covered in the [Security Commands](commands/security) reference) and focus on server-wide concerns: who can use Harbor commands, where logs are posted, and what the overall configuration looks like. You must hold the **Admin** permission level to use any command on this page.

---

### `/harbor setup`

Run the interactive setup wizard. Harbor walks you through the essential configuration steps in order: selecting a log channel, assigning an admin role, assigning a mod role, and enabling your chosen core modules. Run this command when you first add Harbor to your server or whenever you want to reconfigure the basics from scratch.

**Usage:**
```
/harbor setup
```

No parameters required. The wizard runs entirely through Discord's interaction system.

---

### `/harbor config`

Display the full current configuration for your server. Use the optional `module` parameter to narrow the output to a single module's settings.

**Usage:**
```
/harbor config
```

**Options:**

| Parameter | Required | Description |
|---|---|---|
| `module` | No | Filter output to a specific module: `anti-raid`, `anti-nuke`, `anti-spam`, `anti-bot`, `verify`, or `threat-detection`. |

---

### `/harbor config admin-role`

Set the role that grants members access to Harbor admin commands. Members holding this role can use all configuration, security module, and setup commands.

**Usage:**
```
/harbor config admin-role:@Admins
```

| Parameter | Required | Description |
|---|---|---|
| `admin-role` | Yes | The role to designate as the Harbor admin role. |

---

### `/harbor config mod-role`

Set the role that grants members access to Harbor moderation commands. Members holding this role can use ban, kick, mute, warn, history, and similar moderation actions.

**Usage:**
```
/harbor config mod-role:@Moderators
```

| Parameter | Required | Description |
|---|---|---|
| `mod-role` | Yes | The role to designate as the Harbor mod role. |

---

### `/harbor config alert-role`

Set the role that gets pinged when Harbor posts a critical security event. Assign this to your on-call moderation team so they are notified immediately during raids or nuke attempts.

**Usage:**
```
/harbor config alert-role:@Moderators
```

| Parameter | Required | Description |
|---|---|---|
| `alert-role` | Yes | The role to ping on critical security alerts. |

---

### `/harbor logs channel`

Set the general security log channel where Harbor posts all automated actions, manual moderation events, and informational alerts.

**Usage:**
```
/harbor logs channel:#security-logs
```

| Parameter | Required | Description |
|---|---|---|
| `channel` | Yes | The channel to use for general security logs. |

---

### `/harbor logs critical-channel`

Set a dedicated channel for critical-severity alerts only. If configured, Harbor routes high-priority events (raid triggers, nuke detection) to this channel in addition to the general log channel, keeping critical noise separate.

**Usage:**
```
/harbor logs critical-channel:#critical-alerts
```

| Parameter | Required | Description |
|---|---|---|
| `critical-channel` | Yes | The channel to use for critical-severity alerts. |

---

### `/harbor status`

Display a health overview of all Harbor modules, showing which are enabled, whether required permissions and channels are properly configured, and the current state of any active automated responses.

**Usage:**
```
/harbor status
```

No parameters required. Use this command to quickly confirm Harbor is operating as expected after making configuration changes.

---

### `/harbor reset`

Reset **all** Harbor configuration for your server to factory defaults. This includes every module setting, role assignment, threshold, log channel, and whitelist entry.

**Usage:**
```
/harbor reset
```

<Warning>
  This action cannot be undone. All module settings, role assignments, and thresholds will be erased. You will need to run `/harbor setup` or manually reconfigure Harbor from scratch after using this command.
</Warning>

---

<Info>
  Configuration changes take effect immediately. There is no need to restart or reload the bot after making changes.
</Info>
