Harbor System is controlled entirely through Discord slash commands prefixed with `/harbor`. There are no bot prefixes, no message commands, and no external dashboards required — every configuration option, security toggle, and moderation action is available directly inside Discord. All commands are registered as native slash commands, meaning Discord surfaces them automatically with autocomplete and inline parameter hints as soon as you type `/harbor` in any channel.

## Permission Levels

Harbor System uses two permission levels to control access to commands. You do not need to assign both roles — either level grants access to its associated commands.

- **Admin** — Required for all configuration and module management commands. A member qualifies if they have the Discord **Administrator** permission or have been assigned the configured Harbor admin role via `/harbor config admin-role`.
- **Mod** — Required for manual moderation commands and read-only security views. A member qualifies if they hold the configured Harbor mod role or have Discord's built-in **Moderate Members** permission.
