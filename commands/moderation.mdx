Harbor System includes a full set of moderation commands for manual moderator actions, designed to complement its automated security protections. Every manual action is recorded in Harbor's case system alongside automated enforcement events, giving your moderation team a unified audit trail in one place. All commands below require at minimum the **Mod** permission level unless otherwise noted.

---

### `/harbor ban`

Permanently or temporarily ban a member from the server. Optionally delete recent messages sent by the user.

**Usage:**
```
/harbor ban user:@Username reason:"Reason" duration:[DURATION] delete-messages:[DAYS]
```

| Parameter | Required | Description |
|---|---|---|
| `user` | Yes | The member to ban. Accepts a mention or user ID. |
| `reason` | No | A reason for the ban, recorded in the case log. |
| `duration` | No | Duration of the ban (e.g. `7d`, `24h`). Leave blank for a permanent ban. |
| `delete-messages` | No | Number of days of messages to delete (0–7). |

**Permission:** Moderator or Admin

---

### `/harbor kick`

Remove a member from the server. The user can rejoin with a valid invite unless banned.

**Usage:**
```
/harbor kick user:@Username reason:"Reason"
```

| Parameter | Required | Description |
|---|---|---|
| `user` | Yes | The member to kick. |
| `reason` | No | A reason for the kick, recorded in the case log. |

**Permission:** Moderator or Admin

---

### `/harbor mute`

Apply a timeout (mute) to a member for a specified duration, preventing them from sending messages or joining voice channels.

**Usage:**
```
/harbor mute user:@Username duration:[DURATION] reason:"Reason"
```

| Parameter | Required | Description |
|---|---|---|
| `user` | Yes | The member to mute. |
| `duration` | Yes | How long the mute should last (e.g. `1h`, `30m`, `7d`). |
| `reason` | No | A reason for the mute, recorded in the case log. |

**Permission:** Moderator or Admin

---

### `/harbor warn`

Issue a formal warning to a member. Warnings are stored in Harbor's case system and contribute to the member's moderation history.

**Usage:**
```
/harbor warn user:@Username reason:"Reason"
```

| Parameter | Required | Description |
|---|---|---|
| `user` | Yes | The member to warn. |
| `reason` | Yes | The reason for the warning. |

**Permission:** Moderator or Admin

---

### `/harbor history`

View a member's full moderation history as recorded by Harbor System, including all warnings, kicks, mutes, and bans — both manual and automated.

**Usage:**
```
/harbor history user:@Username
```

| Parameter | Required | Description |
|---|---|---|
| `user` | Yes | The member whose history you want to view. |

**Permission:** Moderator or Admin

---

### `/harbor unban`

Remove an active ban from a user, allowing them to rejoin the server.

**Usage:**
```
/harbor unban user:[USER_ID] reason:"Reason"
```

| Parameter | Required | Description |
|---|---|---|
| `user` | Yes | The user ID of the banned member. |
| `reason` | No | A reason for removing the ban, recorded in the case log. |

**Permission:** Moderator or Admin

---

### `/harbor unmute`

Remove an active timeout (mute) from a member before it expires naturally.

**Usage:**
```
/harbor unmute user:@Username reason:"Reason"
```

| Parameter | Required | Description |
|---|---|---|
| `user` | Yes | The member to unmute. |
| `reason` | No | A reason for removing the mute, recorded in the case log. |

**Permission:** Moderator or Admin

---

### `/harbor case`

Look up a specific moderation case by its Harbor case ID. Useful for reviewing the details of a past action or linking cases during an investigation.

**Usage:**
```
/harbor case id:[CASE_ID]
```

| Parameter | Required | Description |
|---|---|---|
| `id` | Yes | The numeric case ID assigned by Harbor when the action was taken. |

**Permission:** Moderator or Admin

---

## Moderation Logs

Every manual moderation action executed through Harbor System is automatically posted to the configured log channel — the same channel used for automated security events. Each log entry includes the acting moderator, the target user, the reason provided, and the case ID for future reference. To set or update the log channel, use `/harbor logs channel:#channel-name`.

<Note>
  Harbor's moderation case system tracks all manual and automated actions. Use `/harbor history user:@Username` to see the full record for any member.
</Note>
