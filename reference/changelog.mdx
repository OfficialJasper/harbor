This page documents all notable changes to Harbor System across every public release. Versions follow semantic versioning: `MAJOR.MINOR.PATCH`. Major versions introduce breaking changes, minor versions add functionality in a backward-compatible manner, and patch versions contain backward-compatible bug fixes.

## v1.0.0 — Initial Release

**New Features**

- Core security modules launched: Anti-Raid, Anti-Spam, Anti-Nuke, Anti-Bot
- Member verification system with reaction, button, and CAPTCHA modes
- Security log channel with structured embeds
- Threat detection engine with configurable risk scoring
- Whitelist system for users, roles, and bots
- Full slash command interface via `/harbor`
- Interactive setup wizard (`/harbor setup`)

---

## v0.9.0 — Beta

**Beta Features**

- Anti-Raid and Anti-Spam modules available to beta testers
- Initial threat detection scoring (experimental)
- Early access verification system

**Known Issues**

- CAPTCHA verification in beta — may have occasional false completions
- Threat score recalculation interval subject to change
