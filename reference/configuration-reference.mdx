This page lists every configurable setting in Harbor System, its default value, the range of accepted inputs, and the slash command used to change it. Use this reference when fine-tuning modules or auditing your server's current configuration. Settings are grouped by module. All commands require the Harbor Admin permission tier unless noted otherwise.

## Global Settings

These settings apply across the entire bot and are not tied to a specific module.

| Setting | Command | Default | Accepted Values | Description |
|---|---|---|---|---|
| `admin-role` | `/harbor config admin-role` | none | `@Role` | Role granted Harbor admin access |
| `mod-role` | `/harbor config mod-role` | none | `@Role` | Role granted Harbor moderator access |
| `alert-role` | `/harbor config alert-role` | none | `@Role` | Role pinged on critical security events |
| `log-channel` | `/harbor logs channel` | none | `#Channel` | Primary channel for security log embeds |
| `critical-channel` | `/harbor logs critical-channel` | none | `#Channel` | Separate channel for critical-only alerts |

## Anti-Raid Settings

| Setting | Command | Default | Accepted Values | Description |
|---|---|---|---|---|
| `enabled` | `/harbor anti-raid enable` / `/harbor anti-raid disable` | `false` | `true` / `false` | Toggles the Anti-Raid module |
| `threshold` | `/harbor anti-raid threshold` | `[DEFAULT]` | Integer ≥ 1 | Maximum number of joins before lockdown is triggered |
| `window` | Part of threshold command | `[DEFAULT]` | 1–60 (seconds) | Time window used to count rapid joins |
| `action` | `/harbor anti-raid action` | `kick` | `kick` / `ban` / `mute` | Action applied to detected raiders |
| `lockdown-mode` | `/harbor anti-raid lockdown-mode` | `role` | `role` / `channel` | Method used to apply server lockdown |
| `notify-role` | `/harbor anti-raid notify-role` | none | `@Role` | Role pinged when a raid is detected |

## Anti-Nuke Settings

| Setting | Command | Default | Accepted Values | Description |
|---|---|---|---|---|
| `enabled` | `/harbor anti-nuke enable` / `/harbor anti-nuke disable` | `false` | `true` / `false` | Toggles the Anti-Nuke module |
| `channel-delete-threshold` | `/harbor anti-nuke channel-delete-threshold` | `[DEFAULT]` | Integer ≥ 1 | Number of channel deletions that triggers Anti-Nuke |
| `role-delete-threshold` | `/harbor anti-nuke role-delete-threshold` | `[DEFAULT]` | Integer ≥ 1 | Number of role deletions that triggers Anti-Nuke |
| `ban-threshold` | `/harbor anti-nuke ban-threshold` | `[DEFAULT]` | Integer ≥ 1 | Number of bans in a window that triggers Anti-Nuke |
| `action` | `/harbor anti-nuke action` | `strip-perms` | `strip-perms` / `ban` | Action taken against the offending account |
| `recovery` | `/harbor anti-nuke recovery` | `true` | `true` / `false` | Whether Harbor attempts to restore deleted channels or roles |

## Anti-Spam Settings

| Setting | Command | Default | Accepted Values | Description |
|---|---|---|---|---|
| `enabled` | `/harbor anti-spam enable` / `/harbor anti-spam disable` | `false` | `true` / `false` | Toggles the Anti-Spam module |
| `max-messages` | `/harbor anti-spam max-messages` | `[DEFAULT]` | Integer ≥ 1 | Maximum messages allowed within the window |
| `window` | `/harbor anti-spam window` | `[DEFAULT]` | 1–60 (seconds) | Time window for message counting |
| `max-mentions` | `/harbor anti-spam max-mentions` | `[DEFAULT]` | Integer ≥ 0 | Maximum mentions allowed per message |
| `max-emojis` | `/harbor anti-spam max-emojis` | `[DEFAULT]` | Integer ≥ 0 | Maximum emojis allowed per message |
| `duplicate-threshold` | `/harbor anti-spam duplicate-threshold` | `[DEFAULT]` | Integer ≥ 1 | Number of identical messages before action is taken |
| `action` | `/harbor anti-spam action` | `delete` | `delete` / `warn` / `mute` / `kick` | Action applied to spamming members |
| `escalation` | `/harbor anti-spam escalation` | `true` | `true` / `false` | Whether repeated offenses trigger progressively harsher actions |

## Anti-Bot Settings

| Setting | Command | Default | Accepted Values | Description |
|---|---|---|---|---|
| `enabled` | `/harbor anti-bot enable` / `/harbor anti-bot disable` | `false` | `true` / `false` | Toggles the Anti-Bot module |
| `action` | `/harbor anti-bot action` | `kick` | `kick` / `ban` | Action taken when an unauthorized bot joins |
| `allow-verified-bots` | `/harbor anti-bot allow-verified-bots` | `true` | `true` / `false` | Whether Discord-verified bots are automatically permitted |
| `dms-on-join` | `/harbor anti-bot dms-on-join` | `false` | `true` / `false` | Whether Harbor sends a DM to a bot account on join before actioning |
| `alert-on-detection` | `/harbor anti-bot alert-on-detection` | `true` | `true` / `false` | Whether the alert role is pinged when a bot is detected |

## Verification Settings

| Setting | Command | Default | Accepted Values | Description |
|---|---|---|---|---|
| `enabled` | `/harbor verification enable` / `/harbor verification disable` | `false` | `true` / `false` | Toggles the Verification module |
| `mode` | `/harbor verification mode` | `button` | `reaction` / `button` / `captcha` | Verification challenge type presented to new members |
| `channel` | `/harbor verification channel` | none | `#Channel` | Channel where the verification prompt is posted |
| `verified-role` | `/harbor verification verified-role` | none | `@Role` | Role assigned to members upon successful verification |
| `unverified-role` | `/harbor verification unverified-role` | none | `@Role` | Role assigned to members pending verification |
| `timeout` | `/harbor verification timeout` | `[DEFAULT]` | Integer ≥ 1 (minutes) | Time before an unverified member is kicked |

## Threat Detection Settings

| Setting | Command | Default | Accepted Values | Description |
|---|---|---|---|---|
| `enabled` | `/harbor threat-detection enable` / `/harbor threat-detection disable` | `false` | `true` / `false` | Toggles the Threat Detection engine |
| `action-threshold` | `/harbor threat-detection action-threshold` | `[DEFAULT]` | 0–100 | Minimum risk score that triggers an automated action |

<Info>
Settings marked with `[DEFAULT]` have placeholder values pending public release. Defaults will be documented here upon launch.
</Info>
