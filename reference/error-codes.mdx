When Harbor System encounters an error, it responds with a structured error message containing a unique code, a short description, and context about the affected command. This page lists all known error codes, their causes, and the recommended steps to resolve each one. If an error persists after following the fix, collect the full error message and report it in the support Discord.

## Error Code Format

Harbor System error codes follow the format `HS-[CATEGORY]-[NUMBER]`, for example `HS-PERM-001`. The category segment identifies which part of the system produced the error:

| Category | Area |
|---|---|
| `PERM` | Permission and access control issues |
| `CFG` | Configuration and setup issues |
| `MOD` | Moderation action failures |
| `SYS` | Internal system and API errors |

## Permission Errors (HS-PERM)

| Code | Message | Cause | Fix |
|---|---|---|---|
| `HS-PERM-001` | Missing required Discord permission | Harbor's bot role lacks a Discord permission needed to complete the action | Open **Server Settings → Roles**, select Harbor's role, and verify all required permissions are enabled |
| `HS-PERM-002` | Role hierarchy conflict | The target role is positioned above Harbor's bot role in the role list | Open **Server Settings → Roles** and drag Harbor's role above the target role |
| `HS-PERM-003` | Insufficient Harbor permission level | The user who ran the command does not hold the required Harbor Admin or Moderator role | Assign the appropriate role to the user, or reconfigure admin/mod roles with `/harbor config` |
| `HS-PERM-004` | Cannot action server owner | A moderation action was attempted against the server owner | Remove the server owner from the action target; Harbor cannot action the server owner under any circumstance |

## Configuration Errors (HS-CFG)

| Code | Message | Cause | Fix |
|---|---|---|---|
| `HS-CFG-001` | Log channel not configured | No log channel has been set and Harbor needs one to complete the action | Run `/harbor logs channel:#your-channel` to configure a log channel |
| `HS-CFG-002` | Invalid role specified | The role provided does not exist or is inaccessible to Harbor | Verify the role name or mention is correct and that Harbor's role can see it |
| `HS-CFG-003` | Module not enabled | You attempted to configure a module that is currently disabled | Enable the module first using the appropriate `/harbor [module] enable` command |
| `HS-CFG-004` | Threshold out of range | The value provided falls outside the accepted range for that setting | Check the accepted value range in the [Config Reference](/reference/configuration-reference) |

## Moderation Errors (HS-MOD)

| Code | Message | Cause | Fix |
|---|---|---|---|
| `HS-MOD-001` | Member not found | The user ID or mention provided does not match any current server member | Verify the user is still in the server; they may have left before the action completed |
| `HS-MOD-002` | Cannot DM member | The target member has DMs disabled or has blocked the bot | Harbor cannot send them a notification, but the moderation action is still applied |
| `HS-MOD-003` | Already actioned | The member already has an active mute or ban from a previous action | Check the member's case history with `/harbor history user:@User` before proceeding |

## System Errors (HS-SYS)

| Code | Message | Cause | Fix |
|---|---|---|---|
| `HS-SYS-001` | Rate limited by Discord API | Too many actions were sent to Discord in a short period | Wait briefly and retry; Harbor handles Discord rate limits automatically in most cases |
| `HS-SYS-002` | Internal error | An unexpected error occurred within the bot | Retry the command once; if the error persists, report it to the support Discord with the full error message |
| `HS-SYS-003` | Service unavailable | Harbor System is undergoing maintenance or is temporarily offline | Check the status page at [status.harborsystem.xyz](https://status.harborsystem.xyz) [PLACEHOLDER] for updates |

<Note>
If you encounter an error not listed here, please report it in the support Discord with the full error message and the command you ran.
</Note>
