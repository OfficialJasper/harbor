Beyond rule-based filters that react to specific actions, Harbor System includes a proactive threat detection engine that assigns a dynamic risk score to every user based on a combination of account-level signals and observed behavior. Rather than waiting for a user to break a rule, threat detection identifies high-risk accounts the moment they join — and continues to evaluate them as they interact with your server. This gives your moderation team early warning and allows Harbor to take pre-emptive action against accounts that have not yet done anything overtly harmful.

## Risk Signals

Harbor System evaluates the following signals when calculating a user's threat score:

- **Account age** — recently created accounts carry a higher base risk score
- **Default or no avatar** — accounts with no profile picture are statistically associated with throwaway and bot accounts
- **No mutual servers or prior history** — accounts with no Discord presence outside this server score higher risk
- **Suspicious invite link** — joining via an invite link associated with previous raid or spam activity
- **Rapid message rate after joining** — sending messages at an unusually high rate immediately after joining
- **Known raider or spam patterns** — username patterns, message content, or join timing that match signatures in Harbor's threat database
- **Previous ban history** — accounts previously banned from other servers in Harbor's threat database network (requires threat database to be enabled)

## Risk Levels

| Level | Score Range | Default Action |
|---|---|---|
| Low | 0–30 | None |
| Medium | 31–60 | Flag and log |
| High | 61–80 | DM warning and increased monitoring |
| Critical | 81–100 | Kick or ban and alert |

## Configuring Threat Detection

To enable the threat detection engine, run:

```bash
/harbor threat-detection enable
```

To set the score threshold at which Harbor automatically takes action, run:

```bash
/harbor threat-detection action-threshold:[SCORE]
```

Replace `[SCORE]` with a numeric value between 0 and 100. For example, setting `action-threshold:70` tells Harbor to take automated action against any user whose score reaches 70 or above.

## Reviewing Flagged Users

To view all accounts currently flagged by the threat detection engine, run:

```bash
/harbor flags list
```

To review the full risk score breakdown for a specific user — including which signals contributed to their score — run:

```bash
/harbor flags review user:@Username
```

This command shows each signal, its individual contribution to the total score, and the timestamp of the last score update. Use this information to decide whether manual action is appropriate or whether a whitelist exemption is warranted.

<Info>
  Threat scores are calculated dynamically and updated as user behavior changes. A user's score can decrease over time with positive server participation.
</Info>

<Note>
  Threat detection is supplemental to other security modules. It is most effective when combined with verification and anti-raid protection.
</Note>
