## Get Up and Running

Follow these four steps to go from zero to a fully protected Discord server.

<Steps>
  <Step title="Add Harbor System to Your Server">
    Use the official invite link to authorize Harbor System and grant the necessary permissions. Make sure you have server owner or administrator access before proceeding.
  </Step>
  <Step title="Run /harbor setup">
    Run the `/harbor setup` slash command to initialize the bot, create required roles, and configure default security settings for your server.
  </Step>
  <Step title="Configure Security Modules">
    Use the `/harbor config` commands to enable and tune individual security modules — including anti-raid, anti-spam, verification, and more — to fit your community's needs.
  </Step>
  <Step title="Review Your Security Logs">
    Check your designated security log channel to confirm Harbor System is active and monitoring. Review flagged events and adjust thresholds as needed.
  </Step>
</Steps>
