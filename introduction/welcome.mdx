This documentation is your complete reference for installing, configuring, and operating Harbor System on your Discord server. It is written for Discord server administrators and moderators who want to understand what Harbor System does, how to set it up correctly, and how to get the most out of its security modules. Whether you are setting up protection for the first time or fine-tuning an existing configuration, this documentation covers everything you need.

## What You'll Find Here

The documentation is organized into six sections, each covering a distinct area of Harbor System.

- **Introduction** — Start here. These pages explain what Harbor System is, what features it includes, and what you need before adding it to your server. If you are new to Harbor System, read through this section first.
- **Getting Started** — Step-by-step instructions for adding Harbor System to your server, running the initial setup, and completing your first configuration pass. Follow this section in order for the smoothest setup experience.
- **Security Modules** — Deep-dive documentation for each security feature, including anti-raid, anti-nuke, anti-spam, anti-bot, verification, and threat detection. Each page explains how the module works, what threats it addresses, and how to configure it.
- **Commands** — A full reference for every slash command available through the `/harbor` interface, including syntax, options, and usage examples.
- **Guides** — Practical, scenario-based walkthroughs for common tasks such as securing a new server, handling an active raid, and setting up a verification gate for new members.
- **Reference** — Supporting material including the FAQ, troubleshooting steps, a glossary of terms, and a changelog.
